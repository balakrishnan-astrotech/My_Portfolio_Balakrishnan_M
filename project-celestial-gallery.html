Celestial Gallery

An astronomy web application presenting curated celestial objects and scientific information through organised gallery and information pages.

HTMLCSSJavaScript

Project overview

Celestial Gallery is a front-end web application I built to present celestial objects — such as planets, stars or nebulae — in an organised, browsable gallery, paired with information pages that explain each object.

Purpose

I wanted to combine my interest in astronomy with web development practice: structuring content clearly, organising a gallery layout, and presenting scientific information in a way that's easy to browse rather than a wall of text.

Technologies used

HTML
Page structure and content organisation for the gallery and information pages.
CSS
Layout and visual styling for the gallery grid and information sections.
JavaScript
Interactivity within the gallery and information pages.

Screenshots / gallery

What I learned

  • Structuring a multi-page website with consistent navigation using plain HTML, CSS and JavaScript.
  • Organising scientific/reference content into a browsable gallery format.
  • Practicing front-end fundamentals without relying on a framework.

Future improvements

[ roadmap ] I plan to continuously expand Celestial Gallery with new astronomy articles, science news, celestial-object information, and other educational updates, while improving the app's search, organisation, and overall user experience.
